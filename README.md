# linked_list_visualizer

## Overview
Linked List Visualizer is an interactive educational tool designed to help users understand and visualize linked list data structures. The project combines a C++ backend with a modern web-based interface to demonstrate how linked list operations work in real time.

The visualizer supports multiple linked list types and provides animated representations of node traversal, insertion, deletion, searching, reversing, and loop detection.

## Features

- Visualize Singly Linked Lists
- Visualize Doubly Linked Lists
- Visualize Circular Linked Lists
- Insert nodes at the beginning, end, or a specific position
- Delete nodes from the beginning, end, or a specific position
- Search for elements with traversal animation
- Reverse linked lists
- Detect loops in linked lists
- Save and load linked list states using JSON files
- Undo previous operations
- Display node addresses and pointer connections
- Interactive and responsive user interface

## Technologies Used

- C++
- HTML
- CSS
- JavaScript
- Node.js

## How to Run

1. Compile the C++ program:
   bash    g++ -std=c++17 -O2 main.cpp -o linkedlist_cli    

2. Start the Node.js server:
   bash    npm install    npm start     

## Educational Purpose

This project was developed to provide a visual understanding of linked list operations and their underlying concepts. It is useful for students learning Data Structures and Algorithms and for anyone interested in understanding pointer-based data structures.
