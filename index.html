Introduction

A linked list is a linear data structure made of nodes. Each node stores data and a link (pointer) to the next node (and sometimes the previous node). Unlike arrays, linked lists don’t require contiguous memory.

Node Example
10 → 20 → 30 → NULL
🧷

Types

There are three commonly used linked list types in practice.

Singly next pointer

Each node points to the next node. Traversal is only forward.

Doubly prev + next

Each node points to both next and previous nodes. Traversal is forward and backward.

Circular tail → head

The last node links back to the head, forming a loop (can be singly or doubly circular).

🛠️

Operations

Common operations you’ll implement and visualize.

  • Insert: at beginning, end, or a specific position
  • Delete: from beginning, end, or a specific position
  • Traverse: visit nodes in order
  • Search: find a value by scanning nodes
  • Reverse: change link direction
  • Detect loop: identify cycles (useful for circular / bugs)
Tip: many linked list operations are \(O(n)\) because you may need to walk node-by-node.
⚖️

Advantages & Disadvantages

Advantages
  • Dynamic size: easy to grow/shrink at runtime
  • Fast inserts/deletes near a known node (no shifting like arrays)
  • Memory flexibility: nodes can live anywhere in memory
Disadvantages
  • No random access: must traverse to reach an index
  • Extra memory: pointers add overhead
  • Cache-unfriendly: scattered nodes can be slower than arrays
